> **Module:** ShopLite Cloud-Native E-Commerce Platform  
> **Environment:** AWS EC2 Multi-AZ (`ap-southeast-1` Singapore)  
> **Target Fleet:**
> - Control Plane: `i-054833e78a1497e80` (`10.0.10.197`)
> - Worker 1: `i-0bc830a92f49d39a4` (`10.0.10.9`)
> - Worker 2: `i-0b78d3ea2b187f0b4` (`10.0.20.236`)

## 1. Overview & Architecture

In Phase 2, Terraform provisioned our AWS infrastructure with zero public IPs on Kubernetes compute nodes in private subnets, fronted by an Application Load Balancer and routed outbound via NAT Gateway.

This guide provides the complete playback sequence to bootstrap the Kubernetes 1.29 cluster across the fleet either via Ansible or via AWS Systems Manager (SSM) Run Command / User Data.

## 2. Playback Sequence

### Step 1: Kernel Tuning & Container Runtime (`containerd`) on All Nodes
Run across `control_plane` and `workers`:

```bash
# 1. Disable swap (Kubernetes requirement)
swapoff -a
sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab

# 2. Kernel modules for container networking
cat <<'EOF' > /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF
modprobe overlay
modprobe br_netfilter

# 3. Sysctl parameters for bridged iptables and IP forwarding
cat <<'EOF' > /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF
sysctl --system

# 4. Install containerd with systemd cgroup driver
apt-get update -y
apt-get install -y apt-transport-https ca-certificates curl gnupg lsb-release
mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg --yes
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" > /etc/apt/sources.list.d/docker.list
apt-get update -y
apt-get install -y containerd.io

mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml
sed -i 's/SystemdCgroup = false/SystemdCgroup = true/g' /etc/containerd/config.toml
systemctl restart containerd
systemctl enable containerd

# 5. Install kubeadm, kubelet, kubectl (v1.29)
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.29/deb/Release.key | gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg --yes
echo "deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.29/deb/ /" > /etc/apt/sources.list.d/kubernetes.list
apt-get update -y
apt-get install -y kubelet kubeadm kubectl
apt-mark hold kubelet kubeadm kubectl
```

---

### Step 2: Initialize Control Plane & Deploy Calico CNI
Run on Control Plane (`10.0.10.197`):

```bash
# 1. Initialize cluster
kubeadm init \
  --pod-network-cidr=192.168.0.0/16 \
  --apiserver-advertise-address=10.0.10.197 \
  --node-name=shoplite-control-plane

# 2. Configure kubectl for root and ubuntu user
mkdir -p /root/.kube /home/ubuntu/.kube
cp -f /etc/kubernetes/admin.conf /root/.kube/config
cp -f /etc/kubernetes/admin.conf /home/ubuntu/.kube/config
chown -R ubuntu:ubuntu /home/ubuntu/.kube

# 3. Apply Calico CNI v3.27.0
kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.27.0/manifests/calico.yaml

# 4. Generate worker join token
kubeadm token create --print-join-command
```

---

### Step 3: Join Workers to the Cluster
Execute the join command generated by Step 2 on Worker 1 (`10.0.10.9`) and Worker 2 (`10.0.20.236`):

```bash
kubeadm join 10.0.10.197:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>
```
