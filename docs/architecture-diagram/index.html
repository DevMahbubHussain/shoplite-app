High-Level Design · System Blueprint

Full System Architecture Topology

End-to-end production architecture: Multi-AZ AWS VPC perimeter, Kubernetes private cluster workloads, reliable Redis queue buffering, GitOps reconciliation, and distributed observability.

🛡️ Security & Trust Boundaries
Direct public ingress to pods or EC2 instances is strictly prohibited. External traffic enters exclusively via the AWS Application Load Balancer across two Availability Zones, terminating public traffic and forwarding to Ingress on private subnets. Kubernetes NetworkPolicy completely isolates PostgreSQL and Redis from unauthorized access.
⚡ High-Integrity Asynchronous Queue
Orders are accepted instantaneously by catalog-api, assigned PENDING status, and pushed to Redis list orders:pending. The headless worker atomically pops items to orders:processing using BRPOPLPUSH, executes business logic, updates database state, and cleans up with LREM.
🔍 Full-Stack Distributed Observability
The platform correlates all telemetry signals in Grafana. Requests passing through POST /orders inject W3C traceparent headers into Redis payloads. The worker extracts the context and emits child spans to Tempo. Single-line JSON logs in Loki link directly to Tempo traces via derived field regex matching.

Object-Oriented Architecture · Clean Code

API Low-Level Design & SOLID Model

Class decomposition, layer isolation (Routers → Services → Repositories), abstract queue interfaces, and immutable Pydantic v2 schemas.

Layer Responsibility & Boundary Rule Clean Code Standard
Routers (routers/) HTTP deserialization, route parameters, response models, and status codes. Zero database queries; delegates all domain execution to Services.
Services (services/) Business logic, validation, W3C trace header injection, and queue coordination. Depends strictly on Repository and Queue interfaces; unit-testable in isolation.
Repositories (repositories/) Isolates database queries and entity hydration with SQLAlchemy AsyncSession. Fully substitutable with in-memory test doubles (LSP).
Worker Consumer (worker/) Manages the reliable Redis queue loop, startup crash recovery sweep, and graceful SIGTERM shutdown. Never exposes public HTTP endpoints; runs as headless non-root consumer.
